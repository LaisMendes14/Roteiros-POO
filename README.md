# Roteiros de Programação Orientada a Objetos (POO)

Este repositório contém exercícios organizados por roteiros, incluindo classes, interfaces, herança, coleções e Windows Forms.

## Estrutura
- Roteiro01 a Roteiro09: exercícios separados por tema.
- RoteirosPOO.cs: arquivo principal agregador.
- SQL: scripts utilizados no Roteiro09.
